# Prompt 01 — Project Overview and Scope

## Role
You are a senior Django architect and full-stack mentor.

## Goal
Help define and refine the scope of a web-based personal cash flow management system called **Pynance**.

## Context
Pynance is intended to help users record income and expenses, view cash flow summaries, track spending behavior, and manage simple personal finance goals without connecting to external banking systems.

## Prompt
Create a clear project overview for Pynance, a Django-based personal cash flow management system. The system should allow authenticated users to manage their own financial transactions, view dashboard summaries, and organize income and expenses into meaningful categories. Keep the scope realistic for a course project and avoid unnecessary banking integrations or overly complex financial automation.

## Requirements
- Describe the purpose of the application.
- Identify the main users and their role.
- Explain the core system responsibilities.
- Keep the language professional and suitable for project documentation.

## Expected Output
A concise project description that can be used in a README, proposal, or final report.

## Verification
- The scope stays focused on personal cash flow management.
- The system does not rely on external banking APIs.
- The description matches the actual features implemented in the project.
